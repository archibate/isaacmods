- Worked around a bug in [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3775184136]Boss Route Planner / Boss路线规划[/url] 0.0.5 that takes the teleport map off the screen — and, on a plain Repentance+, takes down the drawing of every other mod loaded after it. The game offers each mod its turn to draw, one after another, and ends the round the moment one of them hands a value back: everything behind it that frame is simply never drawn. On a drawing turn a returned value means nothing, so returning one is a mistake, and since a returned value is not an error, nothing is written to the log and nothing appears on the console. That mod's badge drawing returns one on every frame. With REPENTOGON it moves that drawing to a REPENTOGON-only HUD turn and holds no ordinary drawing turn at all, which is why the map went missing for some players and not for others.
- Mods are offered their turn in load order, which is alphabetical, and this one is late in the alphabet, so almost anybody can end up standing in front of it. It now asks for an earlier turn, ahead of every mod that asks for nothing in particular — the same shelter MinimapAPI has always taken — and the same for the turns where it reads the floor and saves your settings, since a mod in front can end those rounds too. The cost is that a HUD drawn later can now cover the window, which beats the window never being drawn at all. (thank @Scarlet_Tracer for the report, and for finding which mod it was!)
