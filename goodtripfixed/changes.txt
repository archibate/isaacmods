- Fixed the “disable the old GoodTrip” warning almost never being seen: it spent its five seconds on the title screen, before anyone was in a room, and it could only detect the old mod when that one happened to load first. It now stays on screen until you fix it, and also catches the old mod loading after us and taking the shared name back.
- Fixed the teleport map vanishing entirely if MinimapScale was set to a very small number: since settings became hand-editable, a scale of 0 drew every part of the window at no size at all, which looks exactly like the mod being broken while every setting still reads correct. Out-of-range values are now pulled back into the supported range.
