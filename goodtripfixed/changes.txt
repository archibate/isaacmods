- Arriving at the door a walk would have come in by is off by default now, under a new name (MCM: ArriveAtDoor). It had been on for everyone since 08-29, and both of this week's reports trace to it: a far trip into a room bigger than the screen can only arrive at the right wall by passing through the last room on the way first, and that room is on screen for a moment before the fade — read as the view twitching, or as landing in an empty room and going straight on into the next. Few asked for the door landing and more minded the pass-through, so it is now the choice of whoever wants it. The switch is renamed because every save already holds the old one on, and a new default must not lose to that. (thank @li3397450972 and @Whitor_大白 for the reports!)
- gtconfig.lua is now read with the game's own include instead of require. Two things follow. A `luamod goodtripfixed` picks up an edit to that file at once, where before the first read was kept for the whole game session. And the file can no longer be shadowed: require looks through every mod's folder for a file of that name, and the original GoodTrip ships a gtconfig.lua too, so with both installed the fixed mod could load the old one and silently skip every pin. include only ever reads from this mod's folder.
