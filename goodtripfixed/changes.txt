- TAB + R now asks the game for its own restart button instead of for the R key on the player's input slot. A player on a controller holds a slot that carries no keyboard, so the shortcut had nothing to read there and did nothing, while pressing R by itself still restarted — which is the difference from the original GoodTrip, where this was always the game's button and so kept working. The keyboard R is still read, on the keyboard's own slot. If TAB + R was dead for you, please say whether this release brings it back. (thank @蒸汽平台小众高级名 for the report!)
- Shooting no longer stops in cleared rooms while the teleport window is pinned to the screen. Fire is held back while the pointer sits over that window, so that clicking a room does not throw a tear along with the trip — but it was held for a pointer merely resting there, and resting there is exactly where the pointer stays all game for anyone playing on the keyboard. A room with enemies never showed it, because the window only takes clicks once the room is clear, so it read as shooting breaking the moment a room was cleared, with a familiar caught mid-shot stuck firing the way it faced, and only a quit bringing it back, since the pin is dropped on load. Fire is now held only while the pointer is actually being moved over the window, or a button is down on it. (thank @train.py for the report!)
